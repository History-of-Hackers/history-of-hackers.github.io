Mati Aharoni

Aharoni helped turn a specialist collection of assessment tools into a maintained, widely documented platform. Kali Linux and the training ecosystem around Offensive Security made repeatable lab work and security testing more accessible to practitioners.

Overview

Mati Aharoni is known in the security community by the handle muts. He founded Offensive Security and worked on the transition from BackTrack to Kali Linux, a distribution intended for penetration testing and security auditing.

Kali Linux was developed by Offensive Security as a Debian-based successor to BackTrack. Its documentation emphasizes that its purpose is professional security assessment, rather than a general-purpose operating system; that framing matters because the included tools must be used lawfully and with authorization.

Aharoni's contribution is therefore as much infrastructural as individual: maintaining a common environment for training, research, and testing helps practitioners reproduce work, exchange methods, and learn responsible assessment practice.

Timeline

  • 2006Offensive Security begins operating in the penetration-testing and training community.
  • 2012Aharoni contacts Debian consultant Raphaël Hertzog about building BackTrack's successor on Debian.
  • 2013-03Kali Linux is released as the Debian-based successor to BackTrack.
  • PresentKali Linux remains maintained as a security-assessment distribution with official documentation and verification guidance.

Robert Hansen

Robert Hansen, known by the handle 'RSnake,' is a web application security researcher who built the influential ha.ckers.org security community and XSS Cheat Sheet, co-coined the term 'clickjacking' with Jeremiah Grossman in 2008, and created the Slowloris denial-of-service tool.

Robert Hansen, widely known in the security community by his handle "RSnake," is a web application security researcher recognized for popularizing cross-site scripting (XSS) research and for co-coining the term "clickjacking."

ha.ckers.org and the XSS Cheat Sheet

Hansen ran ha.ckers.org, a web security blog and community site that hosted his XSS Cheat Sheet, a widely referenced catalog of techniques for bypassing XSS input filters. The Open Web Application Security Project (OWASP) later built its own XSS Filter Evasion Cheat Sheet directly on top of Hansen's original work, crediting it explicitly as the basis for the resource.

Clickjacking

In 2008, working under his company SecTheory, Hansen and fellow researcher Jeremiah Grossman found that Adobe Flash Player could be manipulated through a UI-redress technique that tricked users into clicking on hidden or disguised page elements. The pair coined the term "clickjacking" to describe the attack class, and Hansen authored a paper formally defining the term and laying out a coordinated disclosure timeline.

Slowloris and Denial-of-Service Research

In 2009, Hansen released Slowloris, a tool that could take down web servers using comparatively little bandwidth by opening many partial HTTP connections and holding them open. Slowloris drew public attention when it was used as a low-bandwidth denial-of-service tool during the protests following the 2009 Iranian presidential election. Around the same period, Hansen also researched DNS rebinding attacks.

Legacy

Hansen's legacy lies chiefly in community-building around web application security: ha.ckers.org and its associated cheat sheets helped standardize practical XSS testing knowledge while the field was still maturing, and his and Grossman's clickjacking research named an entire category of UI-based web attacks that remains part of standard web security terminology.

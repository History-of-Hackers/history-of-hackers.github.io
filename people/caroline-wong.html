Caroline Wong

Wong's work has helped organizations treat application security as an engineering and leadership practice that can be measured, staffed, and improved over time.

Building security programs

Caroline Wong is an application-security leader and educator whose work centers on building sustainable security programs. Her public work has addressed the practical questions of how teams set priorities, communicate risk, and use metrics without losing sight of the people doing the work.

Security metrics

Wong wrote Security Metrics, a guide to selecting and using measures for security programs. The book frames measurement as a management tool, while cautioning that a metric is useful only when it informs better decisions.

Community work

Alongside industry leadership roles, Wong has taught and spoken about application security and careers in the field. Her work contributes to the professionalization of software security beyond individual vulnerability findings.

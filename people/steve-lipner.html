Steve Lipner

Lipner’s work links vulnerability response and security engineering with a repeatable product-development process.

Steve Lipner is a security engineer and executive whose career has focused on computer and network security and software assurance. At Microsoft he led the Security Response Center and later oversaw work on the Security Development Lifecycle (SDL).

Building security into development

The SDL made security activities an explicit part of the engineering lifecycle, rather than a final-stage response to defects. Lipner has also written and spoken about the organizational practices needed to make secure development durable.

Timeline

  • 1999Joins Microsoft as director of the Microsoft Security Response Center.
  • 2004Takes responsibility for Microsoft’s secure-development process.
  • 2015Retires from Microsoft and becomes executive director of SAFECode.

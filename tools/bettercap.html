bettercap

bettercap consolidated several network-security testing functions in one extensible framework. Because it includes active testing capabilities, it is intended for authorized research and assessment.

bettercap is an open-source network reconnaissance and security-testing framework.

Capabilities

The project documents modules for network discovery, wireless environments, Bluetooth Low Energy, and other protocols.

It also documents man-in-the-middle testing components, which require explicit authorization to use responsibly.

Use

The framework is maintained as portable Go software and is available for multiple operating systems.

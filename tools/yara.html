YARA

YARA is an open-source, rule-based pattern-matching engine designed by Victor Manuel Alvarez at VirusTotal to help malware researchers identify and classify malware samples using textual and binary patterns.

YARA is described by its maintainers as "the pattern matching swiss knife for malware researchers (and everyone else)". It lets analysts write rules combining hexadecimal patterns, text strings, and regular expressions with boolean logic to describe and detect malware families, rather than relying on a single fixed signature. Rules can also embed metadata and leverage built-in modules for parsing formats such as PE and ELF executables. The name is a recursive backronym, alternately expanded as "YARA: Another Recursive Acronym" or "Yet Another Ridiculous Acronym".

Origins at VirusTotal

YARA was designed by Victor Manuel Alvarez, an engineer at VirusTotal, the multi-antivirus scanning service that Hispasec Sistemas launched in June 2004. Google acquired VirusTotal in September 2012, and Alvarez's tool was subsequently published under the VirusTotal organization on GitHub in 2013, where it has been maintained as an open-source project (BSD-3-Clause license) ever since. Earlier development of YARA reportedly predates its move to GitHub, but a precise, independently verifiable first-release date could not be confirmed from primary sources, so it should be treated as unverified/disputed.

Adoption and ecosystem

Over the following decade YARA became a de facto standard in malware research and threat intelligence, integrated into security products and workflows at organizations including Kaspersky Lab, Trend Micro, Cisco Talos, FireEye/Mandiant, and Elastic Security, among many others. It ships with a command-line scanner and a Python binding (yara-python), and runs on Windows, Linux, and macOS. The project has accumulated thousands of commits and a large external contributor base on GitHub.

YARA-X and maintenance mode

In 2024, VirusTotal introduced YARA-X, a from-scratch reimplementation of YARA in the Rust programming language, aimed at improved performance, memory safety, and usability while remaining highly compatible with existing YARA rule syntax. On June 4, 2025, VirusTotal announced that YARA-X had reached a stable 1.0 release; at the same time, the original C-based YARA project entered maintenance mode, meaning it now receives only critical bug fixes and security patches rather than new features, with future development focused on YARA-X. The original YARA continues to receive periodic patch releases (for example, version 4.5.x in 2025-2026) to address build issues and memory-safety findings in its file-format parsing modules.

Because YARA rules can be shared and combined into large public rule sets, the tool is also widely used for threat hunting, incident response, and building detection content pipelines, extending its role well beyond VirusTotal's own scanning infrastructure.

  • 2012-09Google acquires VirusTotal.
  • 2013YARA, designed by VirusTotal engineer Victor Manuel Alvarez, is published on GitHub under the VirusTotal organization as an open-source project.
  • 2020-05-15YARA v4.0.1 is released.
  • 2021-04-26YARA v4.1.0 is released.
  • 2023-09-15YARA v4.4.0 is released.

  • 2026-07-28YARA v4.5.8 maintenance release addresses build issues and memory-safety fixes in PE, ELF, and .NET parsing modules.

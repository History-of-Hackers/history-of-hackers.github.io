Social-Engineer Toolkit (SET)

SET helped standardize social-engineering testing workflows in penetration-testing environments. Its capabilities should be used only with explicit scope and consent.

The Social-Engineer Toolkit (SET) is an open-source framework for authorized social-engineering assessments. David Kennedy created the project in 2009.

Public release history

TrustedSec's November 3, 2010 announcement describes the forthcoming SET 1.0 release and its new automation and web interfaces. This distinguishes the project's 2009 creation from that later public release announcement.

Project and ethics

TrustedSec maintains SET, and the user manual identifies David Kennedy as its author. The software is used in training and authorized penetration-testing exercises; because social engineering involves people as well as systems, engagement rules and explicit organizational authorization are essential.

drozer

drozer provided a reusable framework for examining Android application attack surfaces instead of creating one-off test applications. Its revival and Python 3 support show the continuing need for mobile assessment tooling.

drozer is an open-source Android security assessment framework.

Approach

The project describes testing applications and devices by assuming the role of an Android application and interacting with IPC endpoints and the operating system.

This approach supports repeatable assessment of application exposure and platform behavior.

Project status

Reversec maintains a rewritten Python 3-compatible release and publishes its source and guide.
